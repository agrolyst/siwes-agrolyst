# Signup guide screenshots

Save the signup walkthrough screenshots in this folder using these filenames:

1. `signup-page.png` — the full signup page before entering details.
2. `signup-email-check.png` — the email field and the point where the email is checked (hide the actual email address).
3. `existing-application-redirect.png` — the notice/page shown when an email has already applied and is redirected to link the existing application (hide personal details).
4. `signup-success.png` — the successful signup/next-step screen (hide personal details and any codes).
5. `signup-confirmation-email.png` — a screenshot of the signup confirmation email as received in an inbox (hide the email address, verification code, tokens and private links).

Use PNG format where possible. Do not include passwords, real verification codes, access tokens, student IDs, or other private information in screenshots.
